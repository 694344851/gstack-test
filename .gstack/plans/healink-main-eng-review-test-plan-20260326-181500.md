## Affected Pages/Routes
- `/` workspace shell with `我的作品库` section — verify library/trash switching, modal open/close, and detail rendering
- `GET /library/works` — verify active works only, excludes trashed items
- `GET /library/trash` — verify trashed works only, ordered by `deleted_at DESC`
- `GET /generation-tasks/:id` — verify detail modal loads full task snapshot for active and trashed works
- `PATCH /library/works/:id` — verify rename updates display title while preserving original generated title
- `POST /library/works/:id/trash` — verify completed work moves to trash
- `POST /library/works/:id/restore` — verify trashed work returns to active library
- `DELETE /library/works/:id` — verify permanent delete only works for trashed items

## Key Interactions to Verify
- Click a library card and confirm the detail modal opens with cover, title, audio state, and node list
- Switch between node tabs in the modal and confirm the right artifact content renders each time
- Rename a work in the modal and confirm both the modal title and card title update
- Move a work to trash and confirm it disappears from `全部作品` and appears in `垃圾箱`
- Restore a work from trash and confirm it reappears in `全部作品`
- Permanently delete a trashed work and confirm it no longer appears anywhere and detail fetch returns 404
- Close the modal with close button and `Esc`, keeping the library scroll position

## Edge Cases
- Rename with empty or whitespace-only title
- Rename, trash, restore, or delete against a missing work id
- Attempt permanent delete for an active work
- Attempt restore for a non-trashed work
- Work has no audio URL: player disabled/fallback still allows node inspection
- Legacy database without trash columns: app boot should backfill schema automatically
- Trashed work must not leak into active list even if `status = completed`
- Broken `current_result_json` rows should still be skipped without crashing list endpoints

## Critical Paths
- Active library card → open detail modal → inspect nodes → rename → list updates
- Active library card → trash confirm → switch to trash view → restore → switch back and verify active list
- Active library card → trash confirm → trash view → permanent delete → detail route 404 and card gone
